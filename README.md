server monitor system
beskrivelse: 
dette er prosjekt som er et overvåkningssystem utviklet på Pi. Systemet samler inn informasjon om CPU og RAM bruk. Den lagrer dataene i en MariaDB OG DATABASER.

Målet er å gi IT oersjonell oversikt over serverens status gjennom webbasert dashboard utviklet med flask.

funksjoner:
Overvåke CPU bruk
Overvåke RAM bruk
Lagring av historiske data i MariaDB
Webbasert dashboard med flask
Side med ansatte lagret i databasen
